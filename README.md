🧠 Curso de Backend Node.js – OOLab Guaíba

Bem-vindo(a) ao repositório oficial do Curso de Backend Node.js – OOLab | Node IoT! 🚀

Este curso faz parte da iniciativa da Node IoT para promover o aprendizado prático em desenvolvimento de software, com foco em backend moderno, integração com APIs e boas práticas de engenharia.
Realizado no OOLab da Node IoT, em Guaíba/RS, o programa oferece uma imersão técnica voltada para iniciantes que desejam construir bases sólidas no ecossistema Node.js.

🎯 Objetivos do Curso

Introduzir conceitos fundamentais de programação backend usando Node.js

Compreender a estrutura e o funcionamento de APIs RESTful

Aplicar boas práticas com Express.js, modularização, e versionamento de código (Git/GitHub)

Integrar o backend com bancos de dados e serviços externos

Desenvolver e publicar uma API funcional do zero

🧩 Conteúdo Programático
📍 Módulo 1 – Fundamentos do Node.js

O que é Node.js e seu papel no backend

Configuração do ambiente

Introdução ao npm e package.json

Módulos nativos e criação de scripts básicos

⚙️ Módulo 2 – Criando um Servidor HTTP

Introdução ao Express.js

Estrutura básica de uma API

Middlewares e rotas

Boas práticas de organização de código

💾 Módulo 3 – Persistência de Dados

Conexão com bancos de dados (SQLite ou MongoDB)

Operações CRUD

Modelagem e validação de dados

🧰 Módulo 4 – Versionamento e Deploy

Fluxo de trabalho com Git e GitHub

Controle de versões em equipe

Publicando o backend na nuvem (Render, Railway, ou NodeIoT Cloud)

🚀 Módulo 5 – Projeto Final

Desenvolvimento de uma API de cadastro e autenticação de usuários

🧑‍🏫 Sobre o OOLab | Node IoT

O OOLab é o laboratório de inovação da Node IoT, criado para capacitar talentos e fomentar o ecossistema de tecnologia em IoT, IA e desenvolvimento full stack.
Com sede em Guaíba (RS), o laboratório oferece workshops, bootcamps e cursos técnicos que conectam aprendizado prático com o ambiente de inovação da Node IoT.
